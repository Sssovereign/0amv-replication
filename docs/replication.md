## 3. v5 定型配方（数学定义）

因子（个股层，全 A 股）：

1. **流通股本阶梯**：gbbq cat 2/3 的 `songgu_qianzongguben`（除权后流通）与 cat 5/9/10/13/14 的 `hongli_panqianliutong`（变动后流通），万股；按日期形成 step 函数。
2. **成交记忆**：`mem_i(t) = mem_i(t−1)×(1 − 1/N) + vol_i(t)`，随后 `mem_i = min(mem_i, 流通股本_i)`；尺度 N ∈ {5, 10, 20, 60, 120, 250}。
3. **市场聚合**：`MEM_N(t) = Σ_i mem_i(N,t)×close_i(t)`；`MV(t) = Σ_i 流通股本_i×close_i`；`A(t) = Σ_i amount_i`。

回归（2011-01-01 → 2023-12-31 定系数，2024+ 样本外）：

```
min  ‖Xβ − logO‖² + μ·‖ΔXβ − ΔlogO‖² + α‖β‖²        （μ=100, α=0.01）
X = [z(log MEM_N) ×6, z(log MV), z(log A), 1]         z 统计量取拟合窗口
```

差分权重 μ=100 是 dod 精度与出场召回的平衡点（μ=300 dod 微优但出场召回 78.3→75.0%，μ=1000 水平崩至 95.4% 伤 MA10 判定）。

**评估协议**（主指标=波段触发日对照，非水平相似度）：

- 入场触发：单日 ≥+4% 或连续两日为正且累计 ≥+4%；出场触发：单日 ≤−2.3%；MA10 破位：收盘 ≤ MA10；
- 召回率 = 官方触发日中模型也触发的比例；假信号率 = 模型触发日中官方未触发的比例。

## 4. 日常增量使用

每个交易日盘后：

1. 通达信盘后下载（gbbq 同步自动更新）；
2. （若指南针也更新了）重跑提取器 + `parse_official.py` 核对残差；
3. `python scripts/run_v5.py` —— 读数含义：dod ≥ +4% 且当前非多头 → 入场信号；多头中 dod ≤ −2.3% 或收盘破 MA10 → 出场信号；官方缺失日自动给出纯模型预测。

精度预期：日涨幅误差 <1pp 概率 96.5%；波段信号与官方一致度 ~91%（Jaccard）；已知劣化场景：2015 式停牌潮（成交量结构失真，单日偏差可达两位数 pp）。

## 5. 已否决路线（勿重复试错，均为实测）

| 尝试 | 结果 | 教训 |
|------|------|------|
| 纯成交额衰减池 | dod MAE 1.28pp、Jaccard 0.65 | 缺市值效应 |
| 加大盘杠杆水平因子 | 更差（88.4%） | 日频杠杆是流量性质，不能当水平因子 |
| 长记忆 90/120/250 共线 | 水平 94% 但 Jaccard 0.36 | 长尺度互相对消致日频钝化 |
| 尺度加密 15 档 | 无增益 | 6 档已饱和 |
| 除权日记忆膨胀 | 零效果 | 被 min(·,流通股本) 天然吸收 |
| 数据清洗 + 差分目标 | 全面劣于 v5（0.305pp/0.888） | 巨量成交日正是波段信号载体，不可洗 |
| 训练剔除 2015 停牌潮 | 无救 | 同上 |
| 关键日加权 / 纯价格效应因子 | 无决定性增益 | 与 MEM 差分高度重叠 |
| 在线滚动校准 | 已弃用 | 若恢复必须 K=1（K=20 在偏差快变期滞后） |

## 6. 边界与已知问题

- 官方真值依赖指南针客户端；缺失日只能给纯模型预测，待官方更新后核对；
- 水平存在年尺度 ±3-6% 慢漂移（解禁覆盖度差异），对波段判定无害；
- gbbq cat 5 解禁快照含少量脏点（清洗规则在差分目标下被否决，如需清洗须重验）；
- 本项目为研究产物，未接入任何实盘交易流程；
- 逆向考证记录：指南针 `PayFormulars.dll` 中 `ZNZ_0AMV` 仅为名称表引用，序列 ID 0x3000003 与上证指数同一虚表调用打开——客户端无公式，复现只能走数据拟合。
