# 数据获取指南（全部公开渠道）

本仓库不含任何数据。管线需要三份输入，全部可从公开渠道获得；**每份都不随仓库分发**（版权与体积原因），由每个用户自行获取、自用。

| # | 数据 | 用途 | 来源 | 是否必需 |
|---|------|------|------|----------|
| 1 | 全 A 股日线 `*.day` | 成交记忆/市值/成交额因子 | 通达信免费行情终端 | ★ 必需 |
| 2 | 股本变迁 `gbbq` | 流通股本阶梯 | 通达信（随行情自动更新） | ★ 必需 |
| 3 | 官方 0AMV 日序列 | 回归目标（真值） | 指南针客户端提取 | ★ 回归必需 |

## 1. 通达信日线（免费）

1. 通达信官网 <https://www.tdx.com.cn> 下载免费行情终端（Windows）并安装；
2. 首次使用需补全历史：菜单 `系统 → 盘后数据下载`，勾选沪深 A 股日线，**起始日期建议 2009-01-01**（管线 2010-01-04 起预热、2011 起拟合；从更晚开始会显著缩短可用历史）；
3. 之后每个交易日 15:30 后点一次盘后下载即可保持最新；
4. 数据落盘位置：`<通达信安装盘>/vipdoc/sh/lday/*.day` 与 `vipdoc/sz/lday/*.day`（每记录 32 字节二进制，本仓库 `amv/tdx.py` 直接解析，无需通达信运行）。

覆盖范围过滤已内置：沪市 600/601/603/605/688/689，深市 000/001/002/003/300/301，自动排除指数、B 股、基金与北交所。

## 2. 股本变迁 gbbq（免费，随行情更新）

位置：`<通达信安装目录>/T0002/hq_cache/gbbq`（同目录 `gbbq.map` 是辅助索引）。

- 该文件随通达信盘后下载**自动更新**，无需手工维护；
- 内容是加密的股本变迁事件库（送股/配股/解禁等，约 19 万条）；
- `scripts/parse_gbbq.py` 用开源 [pytdx](https://github.com/rainx/pytdx) 解密为 CSV；
- 取数口径：cat 2/3（配股/送股）的 `songgu_qianzongguben`=除权后流通，cat 5/9/10/13/14（股本变动公告）的 `hongli_panqianliutong`=变动后流通，单位万股。

校验建议：解密后抽查知名公司，如贵州茅台 600519、中国平安 601318 的流通股本应与公开资料一致。

## 3. 官方 0AMV 真值（回归目标，必需）

活跃市值 0AMV（`Z_SK0AMV`）是[指南针](https://www.compass.cn)（北京指南针，300803）商业行情软件中的指标。

**为什么需要它**：0AMV 的计算公式在指南针服务端（客户端逆向证实只是按名接收服务端序列，无本地计算逻辑），因此公开渠道不存在公式，复现只能走"数据拟合"——官方日序列就是拟合的回归目标与残差核对基准。

**如何获取**：

1. 购买/开通含活跃市值指标的指南针软件版本（商业软件，公开销售渠道）；
2. 在本机安装并至少运行一次盘后（数据落盘到本地缓存，如 `F:/Compass/WavMain/`）；
3. 用本仓库自带的提取器导出结构化历史（**只读缓存，不修改指南针任何文件**）：

   ```bash
   python tools/compass_0amv/extract_0amv.py --compass-root "F:/Compass" --output-dir work/compass_out
   ```

4. 把提取结果交给解析脚本：

   ```bash
   python scripts/parse_official.py --compass-dir work/compass_out
   ```

注意：`day.vdat` 被客户端占用（未正常退出）或未更新到最新交易日时，提取器会明确报错而不污染已有数据——按提示退出客户端或先做盘后下载即可。

**版权边界**：官方真值序列属于指南针商业数据，**不得再分发**。本仓库不包含它，你也不要把提取结果提交到任何公开仓库；其他用户应自行提取自用。

## 4. 环境变量与目录约定

| 变量 | 默认 | 含义 |
|------|------|------|
| `TDX_ROOT` | `F:/tdx` | 通达信目录（含 `vipdoc/`、`T0002/hq_cache/gbbq`） |
| `AMV_GBBQ` | `$TDX_ROOT/T0002/hq_cache/gbbq` | gbbq 文件显式路径 |
| `COMPASS_ROOT` | `F:/Compass` | 指南针目录（仅提取真值用） |
| `AMV_WORK` | `<仓库>/work` | 全部产物输出目录（已 gitignore） |

Windows 是最省事的环境（通达信与指南针均为 Windows 软件）。其他平台只要把上述数据文件就位（或用环境变量指到对应路径）同样可跑，CI 即在 Linux 上以合成数据跑全部单测。
